# Okamura canonical generation brief

This brief is intentionally limited to **one image**. Do not ask for animations, frames, sheets, atlases, contact sheets, UI, labels, technical callouts, or props in the same generation.

## Primary source references

Use the four supplied film stills as the identity authority:

- `okamura_body.png` — body build and wide-sleeve silhouette;
- `okamura_clothing.png` — full outfit, trousers, belt, footwear, movement silhouette;
- `okamura_face_01.png` — eyebrows, moustache, goatee, bald head;
- `okamura_face_02.png` — facial proportions and beard profile.

The approved Joe Marshall canonical design is a **style reference only**. Never copy Joe's identity, clothes, hair, anatomy, or proportions.

## Deliver exactly one image

One large, full-body Okamura in a neutral right-facing fighting stance.

Identity and appearance:

- older Japanese man;
- completely bald head;
- stocky/powerful natural build, not bodybuilder-muscular and not lean;
- very thick strongly arched dark eyebrows;
- dark moustache connected to a long pointed goatee;
- stern, intimidating expression;
- loose black V-neck martial-arts top with wide sleeves;
- black trousers;
- black belt;
- black footwear.

Rendering:

- fighting-game cartoon/comic/cel-shaded production art;
- readable silhouette at small game scale;
- consistent clean line/shape treatment with the existing production roster;
- full body comfortably inside the image bounds;
- transparent background preferred; otherwise a single flat clean background suitable for AI-assisted removal;
- enough source resolution to normalize onto a 512x512 production frame.

## Automatic rejection conditions

Reject the generation immediately if any of these occur:

- more than one figure or more than one pose;
- sprite sheet, atlas, grid, contact sheet, infographic, poster, or UI layout;
- any labels, titles, frame numbers, logos, technical text, or panels;
- briefcase, knife, shuriken, gun, or any other prop;
- scenery or environmental background;
- photoreal/3D-render look instead of the roster's stylized fighting-game art;
- hair on the scalp;
- missing/short goatee or incorrect facial hair;
- generic karate gi that loses the loose V-neck/wide-sleeve film silhouette;
- exaggerated superhero musculature;
- cropped head, hands, feet, sleeves, or trousers.

## After acceptance

Save the approved result as:

`assets/characters/okamura/design/okamura_canonical_design.png`

Only then begin animation generation. Each animation batch must use the canonical design as its primary visual reference and must be generated independently from scratch; rejected animation candidates never become production frames.
