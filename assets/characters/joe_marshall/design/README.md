# Joe canonical design

Save the single approved production reference here as:

```text
joe_canonical_design.png
```

It should be a full-body, right-facing, neutral fighting stance in the approved
stylized/cartoon visual language. Identity, outfit, hairstyle, proportions,
palette, outline, shading, and silhouette must be internally consistent and
suitable for normalization onto a 512x512 transparent sprite canvas.

After approval, this image is the primary consistency input for every Joe
animation-generation request. Local movie screenshots become secondary detail
references. Exploratory generations, rejected designs, and raw pose candidates
remain in the Git-ignored `reference/joe_marshall/` development workspace.

Do not place source screenshots in this directory.
