# Okamura canonical design

The first approved production image for Okamura belongs here as:

`okamura_canonical_design.png`

It is the primary visual reference for every later animation batch. Film stills remain secondary references for identity, clothing, facial hair, and proportions.

Acceptance requirements for the canonical image:

- one full-body Okamura only;
- neutral right-facing fighting stance;
- bald older Japanese man with thick arched eyebrows, moustache, and long pointed goatee;
- stocky/powerful proportions;
- loose black V-neck martial-arts top with wide sleeves, black trousers, black belt, black footwear;
- fighting-game cartoon/comic/cel-shaded rendering consistent with the production roster;
- complete head, hands, feet, and clothing inside crop bounds;
- transparent or cleanly removable background;
- no labels, contact-sheet layout, alternate poses, props, scenery, logos, or UI panels.

Do not commit exploratory or rejected generations here.
